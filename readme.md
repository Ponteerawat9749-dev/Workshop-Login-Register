# 🔐 Login & Registration System

ระบบสมัครสมาชิกและเข้าสู่ระบบสำหรับเว็บแอป ใช้งานง่ายด้วย **Username + Password** หน้าตาทันสมัย ใช้งานได้ลื่นไหลทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ สร้างด้วย HTML, CSS และ JavaScript ล้วน โดยมี **Supabase** เป็นหลังบ้านที่ดูแลทั้งการยืนยันตัวตนและการเก็บข้อมูลผู้ใช้

## โปรเจกต์นี้มีอะไรบ้าง

### สมัครสมาชิก
- กรอกชื่อ, นามสกุล, username และรหัสผ่านเพื่อสร้างบัญชี
- แถบวัดความแข็งแรงของรหัสผ่านแบบ 4 ระดับ ช่วยให้ตั้งรหัสที่ปลอดภัยขึ้น
- ตรวจสอบ username ซ้ำ และรหัสผ่านที่ไม่ตรงกันให้ทันที

### เข้าสู่ระบบ
- Login ด้วย username และ password
- มี popup แจ้งเตือนสวย ๆ เมื่อข้อมูลไม่ถูกต้องหรือเข้าสู่ระบบไม่สำเร็จ
- ปุ่มแสดง/ซ่อนรหัสผ่าน พร้อมไอคอนรูปตาที่เปลี่ยนตามสถานะ

### หน้าหลังเข้าสู่ระบบ
- ทักทายด้วยชื่อและนามสกุลของผู้ใช้ พร้อมเครื่องหมาย verified ต่อท้ายชื่อ
- อวาตาร์ตัวอักษรย่อ และการ์ดสรุปข้อมูลโปรไฟล์
- Session คงอยู่แม้รีเฟรชหน้าหรือปิดแล้วเปิดใหม่

### ออกจากระบบ
- ปุ่ม Logout ที่มี dialog ถามยืนยันก่อนเสมอ
- กดยกเลิกแล้วยังอยู่ในระบบต่อ กดยืนยันแล้วกลับสู่หน้า Login ทันที

### ดีไซน์
- การ์ดแบบกระจกเบลอบนพื้นหลังไล่สีที่ขยับช้า ๆ
- แอนิเมชันนุ่มนวลตั้งแต่แท็บสลับ ฟอร์มที่ไหลเข้ามา ไปจนถึงปุ่มและ popup
- ไอคอนประกอบทุกช่องกรอก (คน, กุญแจ, ตา)
- รองรับ Dark Mode อัตโนมัติ และลดแอนิเมชันให้สำหรับผู้ที่ตั้งค่าไว้ในระบบ

### ความปลอดภัย
- รหัสผ่านถูกเข้ารหัสโดย Supabase Auth ไม่มีการเก็บแบบ plain text
- เปิด Row Level Security ผู้ใช้เห็นและแก้ไขได้เฉพาะข้อมูลของตัวเอง
- โปรไฟล์ถูกสร้างโดยฐานข้อมูลเท่านั้น ฝั่งเบราว์เซอร์สร้างหรือลบเองไม่ได้
- ข้อความตอน login ไม่เปิดเผยว่า username นั้นมีอยู่ในระบบหรือไม่

## เทคโนโลยี

| ส่วน | ใช้อะไร |
|------|---------|
| หน้าเว็บ | HTML, CSS, JavaScript (ไม่ใช้ framework) |
| ระบบยืนยันตัวตน | Supabase Auth |
| ฐานข้อมูล | Supabase (PostgreSQL) + Row Level Security |
| ฟอนต์ | Inter |
| ไอคอน | SVG แบบฝังในหน้า |

## โครงสร้างโปรเจกต์

```
login-system/
├── index.html     โครงหน้าเว็บทั้งหมด
├── style.css      ดีไซน์และแอนิเมชัน
├── script.js      ลอจิกสมัคร / เข้าสู่ระบบ / ออกจากระบบ
├── config.js      ค่าเชื่อมต่อ Supabase
├── schema.sql     ตารางโปรไฟล์ trigger และนโยบายความปลอดภัย
├── assert/        ไอคอน verified
└── README.md
```

## เบื้องหลังการทำงาน

Supabase Auth ใช้อีเมลเป็นตัวระบุบัญชี แต่โปรเจกต์นี้ให้ผู้ใช้เข้าด้วย **username** แทน ระบบจึงแปลง username เป็นอีเมลภายในให้อัตโนมัติ ผู้ใช้ไม่ต้องมีอีเมลจริง และไม่ต้องยืนยันอีเมล

เมื่อมีคนสมัคร ฐานข้อมูลจะสร้างแถวในตาราง `profiles` ให้เองผ่าน trigger เก็บชื่อ นามสกุล และ username แยกจากข้อมูลล็อกอิน แล้วดึงมาแสดงหลังเข้าสู่ระบบ

## เริ่มใช้งาน

1. สร้างโปรเจกต์ใน [Supabase](https://supabase.com) แล้วรัน `schema.sql` ใน SQL Editor
2. ที่ Authentication → Providers → Email ปิด **Confirm email**
3. ใส่ `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ใน `config.js`
4. เปิดโฟลเดอร์ผ่านเว็บเซิร์ฟเวอร์ เช่น `npx serve` แล้วเข้า `index.html`
